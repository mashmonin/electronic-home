## Purpose

Отдаёт клиентам информацию по лицевому счёту одним объектом: номер, адрес, помещение и совладельцы, по образцу ресурса `account` смежной системы.

## Requirements

### Requirement: Получение информации по лицевому счёту
Бэкенд SHALL предоставлять эндпоинт `GET /api/accounts/{number}`, возвращающий по номеру лицевого счёта один JSON-объект со статусом `200`. Объект MUST содержать поля:
- `number` — номер лицевого счёта строкой, ведущие нули сохраняются;
- `address` — адрес строкой вида «ул. Тестовая, д. Тест, кв. 1»;
- `premise` — объект с полями `street`, `house`, `apartment`;
- `owners` — список совладельцев счёта, каждый элемент содержит `full_name`.

Имена полей MUST быть в `snake_case`.

#### Scenario: Существующий счёт
- **WHEN** клиент запрашивает `GET /api/accounts/000000000001` при наличии тестовых данных
- **THEN** ответ `200`, `number` равен `000000000001`, `address` равен «ул. Тестовая, д. Тест, кв. 1», `premise` содержит улицу «ул. Тестовая», дом «Тест» и квартиру «1»

#### Scenario: Несколько совладельцев
- **WHEN** у счёта два совладельца
- **THEN** `owners` содержит обоих, отсортированных по ФИО по возрастанию

#### Scenario: Счёт без совладельцев
- **WHEN** у существующего счёта нет совладельцев
- **THEN** `owners` — пустой список, статус `200`

### Requirement: Отсутствующий счёт
Если лицевого счёта с запрошенным номером нет, эндпоинт SHALL вернуть статус `404` без данных о других счетах.

#### Scenario: Неизвестный номер
- **WHEN** клиент запрашивает `GET /api/accounts/999999999999`, а такого счёта нет
- **THEN** ответ со статусом `404`

### Requirement: Только чтение
Эндпоинт MUST NOT изменять данные, а в ответе MUST NOT быть внутренних технических полей хранилища (идентификаторов записей, признака `is_test`).

#### Scenario: Состав ответа
- **WHEN** клиент получает информацию по счёту
- **THEN** в ответе нет полей `id` и `is_test`, а повторный запрос возвращает тот же результат

### Requirement: Доступность через прокси
Эндпоинт SHALL быть доступен клиентам по префиксу `/api` через nginx и, в профиле `dev`, из локального фронтенда по правилам CORS профиля.

#### Scenario: Запрос с локального фронтенда
- **WHEN** фронтенд на `http://localhost:5173` запрашивает эндпоинт в профиле `dev`
- **THEN** запрос не блокируется CORS
