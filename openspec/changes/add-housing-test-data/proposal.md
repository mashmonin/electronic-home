## Why

Модель данных (`housing-data-model`) создана, но таблицы пусты: разрабатывать API и переводить фронтенд с заглушки не на чем. Нужны воспроизводимые тестовые данные в dev-окружении, которые при этом отличимы от настоящих и не попадают в прод.

## What Changes

- Во все пять таблиц (`addresses`, `accounts`, `owners`, `address_owners`, `account_owners`) добавляется булева колонка `is_test` (`NOT NULL`, по умолчанию `false`), по которой тестовые записи отличаются от настоящих.
- Новая миграция с тестовыми данными, помеченными `is_test = true`, применяется только в профиле `dev`.
- Тестовые данные:
  - собственники: «Тестовый Тест Тестович» и «Тестовая Теста Тестовна»;
  - адреса: улица «ул. Тестовая», дом «Тест», квартиры «1» и «2»;
  - лицевой счёт `000000000001` на квартире 1, совладельцы счёта — оба собственника;
  - собственники квартиры 1 — оба; собственник квартиры 2 — «Тестовый Тест Тестович».
- Город в адресе не хранится: колонки `city` нет, «город Тест» в данные не входит (решение владельца).
- В профиле `prod` тестовые данные не создаются.

- `backend/src/test/`: интеграционные тесты наличия данных в `dev`, их отсутствия без контекста `dev` и работы колонки `is_test`.
- Frontend не затрагивается (остаётся на заглушке). Новых зависимостей нет.
