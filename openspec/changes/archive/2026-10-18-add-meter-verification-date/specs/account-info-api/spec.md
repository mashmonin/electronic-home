## MODIFIED Requirements

### Requirement: Счётчики воды и показания в ответе
Каждый элемент `meters` SHALL содержать поля:
- `number` — номер счётчика строкой;
- `water_type` — `HOT` для горячей воды или `COLD` для холодной;
- `verification_date` — дата окончания срока проверки счётчика (`ГГГГ-ММ-ДД`) либо `null`, если дата не задана; сервер MUST NOT вычислять по ней статус;
- `readings` — показания счётчика от новых к старым (по дате, затем по порядку добавления), где каждое показание содержит `value` (число), `reading_date` (дата `ГГГГ-ММ-ДД`) и `previous` — объект с `value` и `reading_date` предыдущего показания либо `null`, если предыдущего нет.

Счётчики SHALL быть отсортированы по номеру по возрастанию. В ответе MUST NOT быть технических полей хранилища (идентификаторов, `is_test`, ссылок на записи).

#### Scenario: Тестовые счётчики
- **WHEN** клиент запрашивает `GET /api/accounts/000000000001` при наличии тестовых данных
- **THEN** `meters` содержит «Тест 1» с `water_type` `HOT` и «Тест 2» с `water_type` `COLD`, именно в таком порядке

#### Scenario: Показания и предыдущее показание
- **WHEN** запрашивается счёт с тестовыми данными
- **THEN** у «Тест 1» первым в `readings` идёт показание `245.300` от 2026-09-25 с `previous` `{value: 230.000, reading_date: 2026-08-25}`, вторым — `230.000` от 2026-08-25 с `previous` `null`

#### Scenario: Квартира без счётчиков
- **WHEN** у квартиры счёта нет счётчиков
- **THEN** `meters` — пустой список, статус `200`

#### Scenario: Счётчик без показаний
- **WHEN** у счётчика нет показаний
- **THEN** его `readings` — пустой список

#### Scenario: Состав вложенных объектов
- **WHEN** клиент получает информацию по счёту со счётчиками
- **THEN** в `meters`, `readings` и `previous` нет полей `id` и `is_test`

#### Scenario: Даты проверки тестовых счётчиков
- **WHEN** запрашивается счёт с тестовыми данными
- **THEN** у «Тест 1» `verification_date` равен `2028-01-01`, у «Тест 2» — `2026-10-17`

#### Scenario: Счётчик без даты проверки
- **WHEN** у счётчика дата проверки не задана
- **THEN** его `verification_date` равен `null`
