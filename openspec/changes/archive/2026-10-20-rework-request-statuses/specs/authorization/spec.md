## MODIFIED Requirements

### Requirement: Полномочия на статусы заявок
Изменять статус заявки (`PUT /api/requests/{id}/status`: взять в работу, подтвердить, выполнено) SHALL быть доступно только администратору. Возвращать выполненную заявку в работу (`POST /api/requests/{id}/reopen`) SHALL быть доступно только автору заявки — собственнику; администратору и жильцу этот эндпоинт запрещён. Жильцу эндпоинты заявок остаются закрыты, как раньше. Собственник может создавать заявку о проверке счётчика только косвенно, изменив срок проверки счётчика своего счёта; администратор при изменении срока заявку не создаёт.

#### Scenario: Администратор меняет статус
- **WHEN** администратор переводит любую заявку на допустимый шаг
- **THEN** ответ `200`

#### Scenario: Собственник меняет статус
- **WHEN** собственник вызывает эндпоинт смены статуса
- **THEN** ответ `403`

#### Scenario: Жилец
- **WHEN** жилец вызывает эндпоинт смены статуса или возврата
- **THEN** ответ `403`

#### Scenario: Автор возвращает в работу
- **WHEN** собственник вызывает возврат своей выполненной заявки с сообщением
- **THEN** ответ `201`

#### Scenario: Администратор возвращает в работу
- **WHEN** администратор вызывает возврат
- **THEN** ответ `403`
