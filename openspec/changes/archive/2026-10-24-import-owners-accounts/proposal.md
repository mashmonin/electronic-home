## Why

В базе есть квартиры 1–138 с показаниями (миграция 020), но нет ни собственников, ни лицевых счетов, ни учётных записей: войти в сервис некому. Список лицевых счетов и ФИО собственников есть в ведомости начислений за сентябрь 2026 (`сентябрь_2026.xls`), по ней нужно заполнить справочник и выдать каждому собственнику вход.

## What Changes

- Из файла берутся только номер лицевого счёта (л/с), ФИО собственника и номер квартиры; суммы долгов и оплат, площади, тарифы и реквизиты ТСЖ не используются и не попадают в репозиторий.
- Новая миграция Liquibase создаёт собственников (`owners`), лицевые счета (`accounts`) и связи (`address_owners`, `account_owners`) для квартир 1–138 с уже существующим адресом «ул. Тестовая, Дом».
- Для каждого собственника создаётся учётная запись `OWNER` (`users` + `user_accounts`) с логином по маске: первая буква имени + первая буква отчества + фамилия, латиницей, строчными (Шмонин Андрей Александрович → `aashmonin`) и с транспортным паролем (BCrypt-хеш в базе).
- Собственник с несколькими лицевыми счетами (одно и то же ФИО) получает одну учётную запись, привязанную ко всем его счетам.
- Персональные данные в git не попадают: в репозитории лежит только скрипт-генератор и описание миграции; SQL с ФИО, логинами и хешами и файл с открытыми транспортными паролями создаются локально в `data/` (в `.gitignore`) и применяются на сервере.
- Организации (ПАО «Ветеринарные препараты», «Юлиян ООО», ООО «НАЯРА») и офисы 1–4 пока пропускаются: для них ничего не создаётся.
- Принудительной смены пароля при первом входе нет (в проекте её нет и не добавляется): «транспортный» пароль — обычный пароль, который собственнику выдают отдельно.

## Capabilities

### New Capabilities

- `owners-accounts-import`: загрузка собственников, лицевых счетов и учётных записей из ведомости начислений; правила логина, транспортного пароля, обработки повторов и пропусков, хранения персональных данных.

### Modified Capabilities

Нет: модель данных и вход в систему не меняются, используются существующие таблицы.

## Impact

- Backend: новый changeset `021-…` в `db/changelog/changes/` и подключение в `db.changelog-master.yaml`; конфигурация запуска (контекст Liquibase и том с файлом импорта) в `docker-compose.prod.yml` / README.
- Новый скрипт-генератор (без персональных данных в репозитории) и каталог `data/` для результатов.
- Данные: 137 лицевых счетов и 128 собственников/учётных записей (по файлу), 8 из них с несколькими счетами.
- Frontend и API не затрагиваются.
