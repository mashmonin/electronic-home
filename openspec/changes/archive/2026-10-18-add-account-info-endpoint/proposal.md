## Why

База уже хранит адреса, лицевые счета и владельцев, но наружу данные не отдаются, а экран ввода показаний работает на заглушке с выдуманными квартирами. Смежная система отдаёт всё по лицевому счёту одним объектом `account` (номер, адрес, помещение и вложенные данные), а не через ресурс «владелец». Делаем так же: центральный ресурс — лицевой счёт.

## What Changes

- Новый эндпоинт `GET /api/accounts/{number}` возвращает одним объектом информацию по лицевому счёту: номер, адрес строкой, помещение (улица, дом, квартира) и список совладельцев счёта (ФИО). Эндпоинт только для чтения; JSON в `snake_case`, как у смежной системы.
- Если счёта с таким номером нет — ответ `404`.
- Фронтенд загружает лицевой счёт с этого эндпоинта и показывает в шапке адрес и номер счёта из ответа, а в окне по иконке профиля — список совладельцев.
- Номер счёта берётся из параметра адресной строки `?account=…`; в режиме разработки без параметра используется счёт по умолчанию `000000000001` (тестовый из сида).
- **BREAKING (для экрана):** выбор квартиры в шапке убирается — один экран показывает один лицевой счёт, а ресурса «список счетов владельца» нет. Заглушка с двумя квартирами удаляется.
- Стояки и показания остаются на заглушке: в БД их нет.
- Авторизация не добавляется (см. design.md, риски).

## Capabilities

### New Capabilities
- `account-info-api`: эндпоинт чтения информации по лицевому счёту — состав ответа, формат, поведение при отсутствии счёта.

### Modified Capabilities
- `meter-readings-screen`: требование «Шапка экрана» заменяется требованием «Шапка экрана с данными лицевого счёта» (адрес и номер счёта из API, без смены адреса); добавляются загрузка лицевого счёта (выбор номера, состояния загрузки и ошибок) и показ совладельцев.

## Impact

- `backend/src/main/java/com/example/electronichome/`: JPA-сущности (только чтение), репозиторий, сервис, контроллер и DTO ответа.
- `backend/src/test/`: интеграционные тесты эндпоинта на Testcontainers.
- `frontend/src/readings/`: клиент API, обработка состояний, изменения `AppHeader`, `MeterReadingsPage`, `readingsApi`, тесты; `frontend/.env.development` с номером счёта по умолчанию.
- Новых зависимостей нет. БД не меняется. nginx уже проксирует `/api`.
