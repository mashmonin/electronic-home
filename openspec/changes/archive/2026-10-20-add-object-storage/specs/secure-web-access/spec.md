## ADDED Requirements

### Requirement: Хранилище не проксируется и пропускает загрузку вложений
nginx MUST NOT проксировать S3 API хранилища: файлы доступны только через эндпоинты бэкенда `/api`. Для путей `/api/requests` nginx SHALL пропускать тело запроса не меньше предела вложений (25 МБ файлов плюс запас на служебные части multipart), для остальных путей `/api` прежний предел сохраняется.

#### Scenario: Загрузка вложений через nginx
- **WHEN** собственник отправляет через nginx сообщение с файлами общим размером 20 МБ
- **THEN** запрос доходит до бэкенда и принимается

#### Scenario: Хранилище недоступно через nginx
- **WHEN** клиент пытается обратиться к S3 API по адресу сайта
- **THEN** такого маршрута нет, запрос не доходит до хранилища

#### Scenario: Предел для остального API
- **WHEN** на путь вне `/api/requests` отправляется тело больше прежнего предела
- **THEN** nginx отклоняет его ответом `413`
