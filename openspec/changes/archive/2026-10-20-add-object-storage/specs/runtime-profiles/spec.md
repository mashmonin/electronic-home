## ADDED Requirements

### Requirement: Ключи доступа к хранилищу
Профиль `prod` SHALL требовать ключ доступа и секретный ключ хранилища объектов (`S3_ACCESS_KEY`, `S3_SECRET_KEY`) из переменных окружения или секретов контейнера без значений по умолчанию; секретный ключ MUST быть не короче 16 символов. Если ключи не заданы или слишком короткие, старт MUST завершаться ошибкой. Профиль `dev` SHALL иметь ключи по умолчанию, пригодные только для разработки.

#### Scenario: Нет ключей в prod
- **WHEN** приложение запускается в профиле `prod` без `S3_ACCESS_KEY` или `S3_SECRET_KEY`
- **THEN** старт завершается ошибкой, значения по умолчанию не используются

#### Scenario: Короткий секрет в prod
- **WHEN** в профиле `prod` секретный ключ хранилища короче 16 символов
- **THEN** старт завершается ошибкой

#### Scenario: Dev без настройки
- **WHEN** приложение запускается в профиле `dev` без переменных окружения хранилища
- **THEN** оно использует ключи для разработки и подключается к локальному хранилищу
