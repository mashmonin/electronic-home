## MODIFIED Requirements

### Requirement: Показания всех квартир за месяц
Система SHALL предоставлять эндпоинт `GET /api/readings?month=ГГГГ-ММ`, возвращающий `{"month": "...", "start": "...", "end": "...", "apartments": [...]}`. В `apartments` попадают все квартиры, у которых есть счётчики воды (квартиры без счётчиков не попадают), отсортированные по номеру квартиры (числа по возрастанию, затем остальные по строке), при равенстве по адресу. Элемент квартиры: `account_number` (номер лицевого счёта квартиры либо `null`, если лицевой счёт ещё не заведён), `apartment`, `address` (как в `GET /api/accounts`), `submitted` (сколько её счётчиков имеют показание за месяц), `total` (сколько у неё счётчиков) и `meters` (по номеру счётчика): `number`, `water_type` (`HOT` или `COLD`) и `reading` — объект `value`, `reading_date`, `previous_value` (значение предыдущего показания счётчика либо `null`), `consumption` (`value` минус `previous_value` либо `null`, если предыдущего нет) — либо `null`, если за месяц показания нет. Если у счётчика за месяц несколько показаний, берётся последнее (по дате, затем по порядку добавления). Показания — числа с тремя знаками после запятой. Ответ MUST NOT содержать технических полей (`id`, `is_test`). Ошибки: `400` — `month` отсутствует, не в формате `ГГГГ-ММ` или позже текущего периода.

#### Scenario: Квартира со сданными показаниями
- **WHEN** запрошен месяц, за который у квартиры 1 есть показания по обоим счётчикам
- **THEN** у неё `submitted` равен 2, `total` равен 2, у каждого счётчика заполнены `value`, `reading_date`, `previous_value` и `consumption`

#### Scenario: Квартира, не сдавшая показания
- **WHEN** за месяц у квартиры нет ни одного показания
- **THEN** квартира в списке, `submitted` равен 0, у всех её счётчиков `reading` равен `null`

#### Scenario: Сдан один счётчик из двух
- **WHEN** за месяц есть показание только по одному из двух счётчиков
- **THEN** `submitted` равен 1, `total` равен 2, у второго `reading` равен `null`

#### Scenario: Первое показание
- **WHEN** у счётчика за месяц первое показание и предыдущего нет
- **THEN** `previous_value` и `consumption` равны `null`

#### Scenario: Расход
- **WHEN** показание 245.300, предыдущее 230.000
- **THEN** `consumption` равен 15.300

#### Scenario: Квартира без лицевого счёта
- **WHEN** у квартиры со счётчиками нет лицевого счёта
- **THEN** квартира в списке, `account_number` равен `null`, показания и метки заполнены как обычно

#### Scenario: Квартира без счётчиков
- **WHEN** у квартиры нет счётчиков воды
- **THEN** её нет в `apartments`

#### Scenario: Порядок квартир
- **WHEN** есть квартиры 2, 10 и 1
- **THEN** порядок: 1, 2, 10

#### Scenario: Неверный месяц
- **WHEN** `month` отсутствует, равен `2026-13`, `октябрь` или месяцу после текущего периода
- **THEN** ответ `400`

#### Scenario: Месяц без показаний
- **WHEN** запрошен прошлый месяц, за который никто не сдавал показания
- **THEN** ответ `200`, все квартиры со счётчиками с `submitted` равным 0
