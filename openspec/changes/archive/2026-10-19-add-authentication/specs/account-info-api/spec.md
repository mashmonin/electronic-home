## ADDED Requirements

### Requirement: Доступ к лицевому счёту только по токену
Эндпоинт `GET /api/accounts/{number}` SHALL требовать аутентификации и доступа к счёту по правилам спецификации `authorization`: без токена — `401`, при отсутствии доступа к счёту — `403`. Состав и формат успешного ответа не меняются.

#### Scenario: Без токена
- **WHEN** клиент запрашивает `GET /api/accounts/000000000001` без токена
- **THEN** ответ `401`

#### Scenario: Собственник своего счёта
- **WHEN** собственник счёта `000000000001` запрашивает его со своим токеном
- **THEN** ответ `200` с прежним составом полей

#### Scenario: Чужой счёт
- **WHEN** собственник запрашивает счёт, с которым не связан
- **THEN** ответ `403`
