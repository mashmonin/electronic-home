## ADDED Requirements

### Requirement: Секрет подписи токенов
Профиль `prod` SHALL требовать секрет подписи JWT из переменной окружения или секрета контейнера без значения по умолчанию; секрет MUST быть не короче 32 байт. Если секрет не задан или короче, старт MUST завершаться ошибкой. Профиль `dev` SHALL иметь значение секрета по умолчанию, пригодное только для разработки.

#### Scenario: Нет секрета в prod
- **WHEN** приложение запускается в профиле `prod` без секрета подписи
- **THEN** старт завершается ошибкой, значение по умолчанию не используется

#### Scenario: Короткий секрет в prod
- **WHEN** в профиле `prod` задан секрет короче 32 байт
- **THEN** старт завершается ошибкой

#### Scenario: Запуск dev без настройки
- **WHEN** приложение запускается в профиле `dev` без переменных окружения для токенов
- **THEN** приложение стартует, вход тестовым пользователем работает
