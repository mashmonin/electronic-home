## ADDED Requirements

### Requirement: Подача показаний только по токену
Эндпоинт `POST /api/accounts/{number}/readings` SHALL требовать аутентификации и доступа к счёту по правилам спецификации `authorization`: без токена — `401`, при отсутствии доступа к счёту — `403`. Роли `ADMIN`, `OWNER` и `RESIDENT` имеют право подавать показания по доступным счетам. При отказе показания MUST NOT сохраняться; остальные правила сохранения не меняются.

#### Scenario: Без токена
- **WHEN** клиент отправляет показания без токена
- **THEN** ответ `401`, ничего не сохранено

#### Scenario: Чужой счёт
- **WHEN** собственник отправляет показания по счёту, с которым не связан
- **THEN** ответ `403`, ничего не сохранено

#### Scenario: Жилец своего счёта
- **WHEN** жилец связанного счёта отправляет допустимые показания
- **THEN** ответ `201`, показания сохранены
