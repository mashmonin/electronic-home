## ADDED Requirements

### Requirement: Полномочия на изменение срока проверки счётчика
Загрузка акта проверки (`POST /api/accounts/{number}/meters/{meterNumber}/verification-act-uploads`) и изменение срока проверки (`PUT /api/accounts/{number}/meters/{meterNumber}/verification-date`) SHALL быть разрешены администратору для любого счёта и собственнику для его счетов (счетов, связанных с учётной записью). Жильцу эти операции MUST быть запрещены (`403`), как и собственнику для чужого счёта; запрос без токена получает `401`. Полномочия определяются на сервере по роли и связи со счётом.

#### Scenario: Администратор
- **WHEN** администратор загружает акт и меняет срок проверки счётчика любого счёта
- **THEN** операции разрешены (`201` и `200`)

#### Scenario: Собственник своего счёта
- **WHEN** собственник, связанный со счётом, меняет срок проверки его счётчика
- **THEN** операция разрешена

#### Scenario: Собственник чужого счёта
- **WHEN** собственник обращается к счётчику счёта, с которым не связан
- **THEN** ответ `403`, ничего не сохранено

#### Scenario: Жилец
- **WHEN** жилец, связанный со счётом, загружает акт или меняет срок проверки
- **THEN** ответ `403`

#### Scenario: Без токена
- **WHEN** запрос без токена
- **THEN** ответ `401`

### Requirement: Полномочия на статусы заявок
Изменять статус заявки (`PUT /api/requests/{id}/status`) SHALL быть доступно только администратору, в том числе подтверждать заявки о проверке счётчика. Собственнику и жильцу эндпоинт запрещён. Собственник может создавать заявку о проверке счётчика только косвенно, изменив срок проверки счётчика своего счёта; администратор при изменении срока заявку не создаёт.

#### Scenario: Администратор меняет статус
- **WHEN** администратор переводит любую заявку на допустимый шаг
- **THEN** ответ `200`

#### Scenario: Собственник меняет статус
- **WHEN** собственник вызывает эндпоинт смены статуса
- **THEN** ответ `403`

#### Scenario: Жилец
- **WHEN** жилец вызывает эндпоинт смены статуса
- **THEN** ответ `403`
