## Context

Меню профиля собирается в `AppHeader.tsx`: вверху `user.login` и `ROLE_NAMES[user.role]`, ниже для любого пользователя со счётом блок «Совладельцы счёта» из `account.owners`. Данные счёта уже загружены экраном (`account` в props), новых запросов не нужно. Причины и ожидаемое поведение — см. proposal.md.

## Goals / Non-Goals

**Goals:**
- Показать в профиле собственника ФИО собственников счёта вместо логина, друг под другом, без блока совладельцев.

**Non-Goals:**
- Изменение API (`owners` остаётся списком), модели данных и других экранов (заявки, шапка).
- Выбор между несколькими счетами у одного пользователя: профиль показывает собственников счёта открытого экрана.

## Decisions

1. **Источник ФИО — `account.owners`** уже загруженного счёта, а не новый запрос и не `GET /api/auth/me` (в нём нет ФИО). Альтернатива — добавить ФИО в `/api/auth/me`: затронет backend и спецификацию `authentication` ради одного окна.
2. **Только для роли `OWNER`**: у `ADMIN` счёта нет, у `RESIDENT` ФИО жильца в `owners` нет — для них остаётся логин и роль.
3. **Запасной вариант — логин**, если `account` ещё не загружен или `owners` пуст: профиль не остаётся без имени.
4. **Вёрстка**: тот же `Flex vertical`, что и раньше; ФИО — `Typography.Text strong` по одному на строку, под ними роль `type="secondary"`. Лишний блок и подпись «Совладельцы счёта» удаляются.

## Risks / Trade-offs

- [Собственник со счётом, где есть и другие собственники (семья), увидит ФИО всех] → это и требуется: «собственников несколько — друг под другом».
- [Тесты ищут «Совладельцы не указаны»/«Совладельцы счёта»] → обновить в `MeterReadingsPage.test.tsx` и `App.test.tsx`.
